# 每侧 200° 统一处理验收

用户明确确认最终安全检查也采用约 200° 区域，不考虑排除区域中的点云。

## 当前行为

- 原始 `/scan_left`、`/scan_right` 仍为 721 束 / 360° / 10 Hz，不修改传感器配置。
- 感知、规划、最终检查统一采用左侧 [-50°,150°] / 右侧 [-150°,50°]；每侧包含边界共 401 个角度采样。
- 统一删除采集时落在车体轮廓内的点，保留有效且不超过 4.5 m 的障碍点。先过滤、再发布 `/unified_scan_*`，不再让局部跟随器收到内部支路已排除的自体回波。
- 健康检查只统计选定角域，区域内无效数据过多不更新新鲜度；范围外数据不影响当前输入健康状态。
- GUI 同步角度范围，并继续进行仅显示层的三维 box 外观遮挡裁剪。感知采用的是所选角域和自体回波过滤，不是 GUI 三维求交结果。
- 已经观测过的门框记忆保留，不随当前视场变化立即删除。

## 明确限制

当前两侧角域合并后正后方约 60° 不受当前扫描检查覆盖。范围外、遮挡区及被过滤点不是经证实的自由空间；未增加通用未知空间模型。本配置不提供盲区内倒车、原地转向安全保证。过去完整 360° 输入下的验收不能直接沿用。
