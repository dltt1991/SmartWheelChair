# Gazebo 显示调整验收

本轮仅修改显示，保留此前窄门修复及门洞绿色标记。

- 默认 M6 地图：全图俯视，中心 `(0, 0)`、高度 22 m，保留鼠标 orbit 操作。
- 删除模型的十条绿色装饰性雷达射线；真实原生扫描区域仍显示。
- 左雷达青蓝、右雷达紫蓝，各自独立材质。按用户澄清，扫描不透明度从 0.035 提高至 0.08，使区域更明显，而非调淡。
- 轮椅所有实体 visual 使用 0.35 透明度；碰撞体不变。此原生材质也影响后摄中轮椅的外观。

## 验证

先修改测试：模型检查因绿色射线未删除、无半透明和旧相机位置失败；原生渲染因左右雷达颜色未区分失败。实施后上述检查全部通过。

- 完整 catkin 构建及回归：384 项，0 错误、0 失败、0 跳过。
- 原生渲染：两个雷达各四个动态渲染对象颜色与 diffuse/manual texture alpha 正确；原始共享 Gazebo 材质未修改，GUI-only 标志有效。
- 左右各 76 帧扫描未改变，均为 10 Hz，后摄得到 112 帧有效图像。相机检查不是逐像素比较。
- 门洞绿线坐标、颜色、清空、超时和槽位上限检查继续通过；60 个轨迹槽位反复显隐后稳定。
- XML 对比确认：去除 visual 后，轮椅模型与此前 HEAD 完全一致；去除 gui 后，地图完全一致。未改变传感器、碰撞体、驱动配置和控制逻辑。本轮未重复执行上一轮 120 例过门矩阵。
- 重启后恢复保存的轮椅位置 `(-5.732873, -3.276917)`，初始速度置零；实际查看截图，默认全图俯视、无绿色装饰射线，双色扫描区域和半透明轮椅可见。
